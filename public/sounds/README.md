# Sons de feedback

Coloque aqui os 5 arquivos .mp3 que o app espera:

- `correct.mp3` — chime curto de acerto
- `wrong.mp3` — buzzer suave de erro
- `level-up.mp3` — fanfarra ao subir de nível
- `streak.mp3` — chama crepitando ao manter ofensiva
- `lesson-complete.mp3` — confetti sonoro

Fontes recomendadas (CC0/livre):
- https://freesound.org (filtre por "Creative Commons 0")
- https://opengameart.org/content (categoria SFX, licença CC0)
- https://kenney.nl/assets (CC0)

Sem esses arquivos, o app continua funcionando — o `useSfx()` engole erros silenciosamente.
